## 📋 About

Professional portfolio built with **React + TypeScript + Vite**, featuring responsive design, i18n support, and organized sections to showcase projects, skills, and experience.

### 🎯 Sections

- **👤 About Me** — Personal and professional introduction
- **🛠️ Skills** — Daily tools and technologies
- **📂 Projects** — Project gallery
- **💼 Experience** — Career history and open source contributions
- **📞 Contact** — Links to email, WhatsApp, LinkedIn, and GitHub

### ✨ Features

- 🌓 **Dark/Light theme** with `localStorage` persistence
- 🌐 **Internationalization (i18n)** — Portuguese and English
- 📱 **Responsive design** for all devices
- ⚡ **Hosted on Vercel** with continuous deployment

---

## 🚀 Deploy

Hosted on Vercel:

🔗 **https://meu-portfolio-ebon-omega.vercel.app**

### Run locally

```bash
# Clone
git clone https://github.com/ismaeldouglasdev/meu-portfolio.git
cd meu-portfolio

# Install dependencies
pnpm install

# Start dev server
pnpm dev

# Build for production
pnpm build
```
